# Nine Lives Software

*adventures worth dying for*

The public home of Nine Lives Software's games, published with GitHub Pages:
**https://phonie-bytes.github.io/nine-lives-software/**

| Game | Release | Play | Download |
|---|---|---|---|
| NOIR: The Midnight Ledger | Release 1 (v5.4.1) | [in your browser](https://phonie-bytes.github.io/nine-lives-software/games/noir/play/) | [Windows .exe](https://github.com/phonie-bytes/nine-lives-software/releases/tag/noir-v5.4.1) |

This repository holds only the **published** games (built files, manuals, pictures).
The games' source code is kept privately.

- `index.html` - the studio page
- `games/<game>/` - each game: its page, `play/` (the browser edition), `docs/` (manual, walkthrough, history)
- Windows builds are attached to this repository's [Releases](https://github.com/phonie-bytes/nine-lives-software/releases)
